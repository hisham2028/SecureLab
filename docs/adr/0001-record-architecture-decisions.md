# ADR 0001: Record architecture decisions

- Status: Accepted
- Date: 2026-11-17

## Context

The roadmap (Phase 0) asks for ADRs covering OS, desktop shell, execution provider, hosting and
authentication before implementation proceeds.

## Decision

Keep short ADRs in `docs/adr/`, numbered, one decision each. Superseded ADRs stay in place with
their status changed.

## Open decisions (not yet recorded)

- Hosting model: managed cloud, institution-hosted, or hybrid, and whether lab machines reach the
  backend over a local network.
- Student exam credential: exam code plus per-student PIN, or an institution identity provider.
- AI assistance provider and data-retention policy.
